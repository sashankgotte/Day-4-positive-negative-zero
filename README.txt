# Day 4: Positive, Negative or Zero

## 📌 Description
This is a beginner-friendly Python program that checks whether a given number is positive, negative, or zero using conditional statements.

## 🎯 Objective
To learn how to use `if`, `elif`, and `else` statements in Python.

## 💻 Python Code
```python
n = int(input("Enter a number: "))

if n > 0:
    print("Positive")
elif n < 0:
    print("Negative")
else:
    print("Zero")
```

## ▶️ Sample Outputs

**Example 1: Positive Number**
```text
Enter a number: 10
Positive
```

**Example 2: Negative Number**
```text
Enter a number: -5
Negative
```

**Example 3: Zero**
```text
Enter a number: 0
Zero
```
